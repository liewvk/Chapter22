# Chapter22

Java repository for Chapter 22.

## Overview

This repository contains Java source code and exercises for Chapter 22.

## Requirements

- Java 8 or later

## Build & Run

To compile all .java files:

```sh
javac -d out $(find . -name '*.java')
```

To run (replace `com.example.Main` with the project's main class):

```sh
java -cp out com.example.Main
```
